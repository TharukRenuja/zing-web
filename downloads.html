Build from Source

Compile zing yourself

Requires Rust 1.75+ and Cargo. Clone the repo and build in release mode.

git clone https://github.com/TharukRenuja/zing.git
cd zing
cargo build --release

v0.2.6

v0.2.6 (Browser Extension Support)

Browser Extension

  • Install native host manifests for all Chromium-based browsers automatically
  • Scans ~/.config/, ~/.var/app/ (Flatpak), ~/snap/ (Snap) — no more hardcoded browser names
  • Fixed gecko extension ID to oss.zing.intercept@tharukrj
  • Chrome/Edge/Firefox/Brave/Helium/Vivaldi/Chromium — all covered with one command

Setup 

zing extension install
# auto-discovers all browsers

zing extension uninstall  
# removes all manifests

Then install the extension: https://github.com/TharukRenuja/zing-interceptor

Other

  • Updated tray and packaging icons
  • Version bump to 0.2.6

Full Changelog: https://github.com/TharukRenuja/zing/compare/v0.2.5...v0.2.6
