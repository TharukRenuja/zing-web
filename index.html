Features

Built for speed.

Every feature is designed to maximize download speed while being intelligent about server capabilities and network conditions.

Segmented Downloads

Split files into parallel byte-range segments. Each connection downloads its own chunk simultaneously.

Adaptive Connections

Measures real per-connection speed, then calculates the optimal connection count. No wasted overhead.

Server Probing

Detects HTTP/2, HTTP/3, bandwidth, RTT, and range support before choosing the best download strategy.

Resume & Recovery

Automatic resume with binary control files. Verify each block against the file on disk.

Daemon Mode

Background service with persistent queue. TUI connects as a live dashboard, CLI submits tasks remotely.

Retry & Mirror Fallback

Automatic retry with exponential backoff. Failover to mirror URLs when a source becomes unavailable.

Terminal UI

Beautiful TUI with task list, per-connection speed, block map visualization, and log panel.

Browser Extension

Capture downloads from Chrome and Firefox directly into zing with Native Messaging.

Desktop GUI

Native Tauri v2 app with dark/light themes, drag & drop, clipboard monitoring, and category organization.

Interfaces

Use it your way.

CLI for power users, TUI for visibility, GUI for everyone, extension for convenience.

Command-line power

Pipe zing into scripts, automate downloads, and control every detail from the terminal.

  • Single-command downloads with full flag control
  • Resume any interrupted download automatically
  • Metalink and batch URL support
  • Output formatting for scripting and parsing

Terminal dashboard

A real-time view of all your downloads. See per-connection speeds, block maps, and logs without leaving the terminal.

  • Task list with status, progress, speed, and ETA
  • Per-connection detail with live speed graphs
  • Block map visualization showing download progress
  • Color-coded log panel with filter levels

Native desktop app

A polished Tauri v2 application with dark and light themes, drag & drop, clipboard monitoring, and a category-based sidebar.

  • Dark/light theme with 7 accent color choices
  • Add Download with category, speed limit, and advanced options
  • Block map visualization and per-connection detail
  • Post-download actions: shutdown, sleep, hibernate, or quit

One-click capture

Install the browser extension and every download automatically goes through zing. Filter by file type or domain.

  • Chrome and Firefox via Native Messaging
  • File type and domain-based interception filters
  • Configurable connections, concurrent tasks, and speed limits
  • Stats dashboard with intercepted, ignored, and detected counts
