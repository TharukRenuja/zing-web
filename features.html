zing is a modern HTTP download manager built for speed, reliability, and developer experience.

Segmented Concurrent Downloads

Split any file into parallel byte-range segments, each downloaded by its own connection simultaneously. Finish large files in a fraction of the time.

  • HTTP/1.1, HTTP/2, and HTTP/3 support via reqwest
  • Binary control files for crash-safe resume
  • Per-block hash validation with Metalink support

Adaptive Connection Count

No more guessing. zing measures real per-connection speed, then calculates the optimal number of connections based on your bandwidth and the server's capacity.

  • Files under 200 MiB: single connection, zero overhead
  • Large files: 2-3 second measurement, then optimal count
  • Dynamic minimum segment size based on connection count
  • Work stealing redistributes from slow to fast connections

Server Intelligence Probing

Before downloading, zing probes the server to detect protocol version, bandwidth, RTT, and range support. This intelligence drives every download decision.

  • Auto-detects HTTP/1.1, HTTP/2, HTTP/3
  • Measures RTT and bandwidth for mirror ranking
  • Falls back to streaming for servers without range support
  • Mirror pre-probing by RTT for fastest failover

Resume & Recovery

State is saved to binary control files every 2 seconds. On resume, each bit is verified against the actual file on disk. Never re-download completed work.

  • Binary control files with block bitfields
  • Periodic save + clean shutdown save
  • Automatic resume from daemon or CLI
  • Bitfield verification on resume

Terminal UI

A beautiful, responsive TUI built with ratatui. Manage downloads, view per-connection speeds, see the block map, and read logs — all from the terminal.

  • Task list with status, progress, speed, ETA
  • Per-connection detail view with live speed
  • Block map visualization (dots grid)
  • Log panel with color-coded levels

Desktop GUI

A native Tauri v2 application with dark and light themes, drag & drop, clipboard monitoring, and a polished interface for managing all your downloads.

  • Dark/light theme with 7 accent color choices
  • Settings: Appearance, General, Network, Bandwidth, Downloads, Schedule, About
  • Add Download with category, speed limit, User-Agent, referer, proxy, and mirror URL
  • Confirm window: overwrite, download as, or cancel on file conflicts
  • Block map visualization, bottom info bar, and category sidebar
  • Post-download actions: shutdown, sleep, hibernate, or quit

Browser Extension

Capture downloads from Chrome and Firefox directly into zing via Native Messaging. Filter by file type or domain, and configure connections and speed limits right from the popup.

  • Chrome and Firefox support via Native Messaging
  • File type and domain-based interception filters
  • Configurable connections, concurrent tasks, and speed limits
  • Stats dashboard: intercepted, ignored, and detected counts
  • Default downloads directory and User-Agent configuration

Daemon Mode

Run zing as a background daemon with JSON-RPC over Unix socket (Linux) or TCP (Windows). Manage downloads from TUI, GUI, CLI, or browser extension.

  • JSON-RPC protocol with auth tokens
  • Session persistence across restarts
  • Scheduled downloads with bandwidth windows
  • Event streaming for real-time updates

Retry & Mirror Fallback

Failed connections retry with exponential backoff + jitter. After exhausting retries, zing rotates to the next mirror. Metalink files provide automatic mirror discovery.

  • Exponential backoff with jitter (500ms - 10s)
  • Multi-URL mirror fallback
  • Throttle detection → reprobe → failover
  • Metalink per-block hash validation
