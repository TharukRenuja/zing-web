Get Started

zing is a modern HTTP download manager built in Rust. Segmented downloads, adaptive connections, resume support, and a clean TUI — designed to be fast, reliable, and easy to use.

Install

One command to install on Linux or macOS:

curl -fsSL https://raw.githubusercontent.com/TharukRenuja/zing/main/install.sh | sh

Or build from source (requires Rust 1.75+):

git clone https://github.com/TharukRenuja/zing.git
cd zing
cargo build --release

Quick start

Download a file:

zing https://example.com/file.zip

Launch the TUI:

zing tui

Start the daemon:

zing daemon start
